# 发布与故障处理

## 需求

正式链路为校验、frozen 构建、扫描、Draft 资产上传、公开 Release。Tag 推送不等于发布成功。

## 架构

包版本 Tag 为 `v<version>`；共用工具发行使用 `tool-v<version>`，不得混触发。
Release 必须包含包、包 SHA-256、发布投影 bepack.json、bepack-release.json 和 scan-report.json。
扫描恶意或可疑检出、扫描不可用、兼容未知均阻断发布。已公开版本不得覆盖。
作者只保管自身 VT_API_KEY 和上传授权，不接收官方 registry 写凭证。
发布成功但尚未收录必须独立展示，不撤销作者 Release。

## 备注

远程 origin 已配置，但 Actions、解析/打包和扫描尚未接入，不能执行上述发布。当前 validate 报告的 `release_checked` 始终为 false，不能用 valid=true 替代发布前检查。

后续接入工作流时固定可信工具摘要和完整 Actions 提交，不使用 main/latest 作为可信工具版本。
